# DeepSea Agent 架构文档

## 架构概述

DeepSea Agent 是一个基于规则引擎的智能代理框架，采用事件驱动和响应式设计模式，能够根据配置的规则动态处理用户输入并生成响应。该框架的核心理念是将复杂的智能代理行为拆分为可配置的规则集，每个规则可以根据上下文条件触发，并执行相应的工具调用或生成新的规则。

## 核心组件说明

### Agent

Agent 是框架的入口点，负责初始化配置、事件总线、可观察上下文和规则调度器。它提供了运行动态对话流程的主要接口。

**主要职责**：
- 初始化系统组件
- 处理用户输入
- 管理对话历史
- 提供输出流

### AgentConfigEngine

配置引擎负责从YAML文件加载和解析Agent配置，包括系统提示、规则定义等。

**主要职责**：
- 加载meta配置
- 加载并渲染系统提示
- 加载规则配置
- 构建AgentConfig对象

### ObservableCtx

可观察上下文是一个响应式数据存储，当数据发生变化时会通过事件总线通知订阅者。

**主要职责**：
- 存储和管理上下文数据
- 发布数据变更事件
- 提供数据访问接口

### EventBus

事件总线实现了发布-订阅模式，用于组件间的解耦通信。

**主要职责**：
- 注册事件订阅
- 发布事件
- 分发事件到订阅者

### RuleDispatcher

规则调度器负责根据上下文变化评估规则条件，并调度符合条件的规则任务执行。

**主要职责**：
- 管理规则任务
- 监听上下文变化
- 评估规则条件
- 调度任务执行
- 提供输出流

### RuleTask

规则任务封装了单个规则的执行逻辑，包括条件评估、工具调用和结果处理。

**主要职责**：
- 评估规则条件
- 准备工具调用参数
- 执行工具调用
- 处理工具调用结果

### ToolCenter

工具中心是工具的注册表，提供工具的注册、获取和调用功能。

**主要职责**：
- 注册工具
- 获取工具定义
- 执行工具调用

### Tool

工具是框架的扩展点，提供了执行特定功能的接口。

**主要职责**：
- 定义工具接口
- 实现特定功能

### LLMCallTool

LLM调用工具是一个具体的工具实现，用于调用大型语言模型。

**主要职责**：
- 渲染提示模板
- 构建工具定义
- 调用LLM客户端

### OpenAIClient

OpenAI客户端封装了与OpenAI API的交互逻辑。

**主要职责**：
- 准备API调用参数
- 发送API请求
- 处理流式响应
- 处理工具调用

## 数据流

1. **初始化流程**：
   - Agent加载配置
   - 初始化事件总线、可观察上下文和规则调度器
   - 注册初始规则

2. **用户输入处理**：
   - Agent接收用户输入
   - 将用户输入设置到上下文
   - 将用户输入添加到对话历史

3. **规则评估与执行**：
   - 上下文变化触发事件
   - 规则调度器接收事件并评估规则条件
   - 符合条件的规则被调度执行
   - 规则任务执行工具调用

4. **工具调用**：
   - 规则任务准备工具调用参数
   - 工具中心执行工具调用
   - 工具调用结果被处理

5. **输出生成**：
   - 规则任务处理工具调用结果
   - 结果可能被设置到上下文、直接返回给用户或生成新规则
   - Agent从规则调度器获取输出流并返回给用户

## 扩展点

1. **添加新工具**：
   - 实现Tool接口
   - 注册到ToolCenter

2. **添加新规则**：
   - 创建新的规则配置
   - 添加到Agent配置

3. **添加新LLM客户端**：
   - 实现LLMClient接口
   - 在LLMCallTool中使用

## 配置系统

配置系统基于YAML文件，包括以下主要部分：

1. **meta.yaml**：
   - 定义Agent的元数据
   - 定义Agent的名称和描述

2. **system_prompt.yaml**：
   - 定义系统提示模板
   - 支持Jinja2语法

3. **rules/*.yaml**：
   - 定义规则配置
   - 包括规则名称、依赖上下文、匹配条件、提示、工具调用等
